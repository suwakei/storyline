## C. エッジの拡大図

```
forward（既定）:
  ┌──────┐              ┌──────┐
  │ 田中  │──────┤兄妹├──────▶│ 鈴木  │
  └──────┘              └──────┘
            ↑ ラベル箱: bg-surface（不透明）+ border-line 1px + 角丸4px
              text-[11px] text-fg / px-1.5 py-0.5 / 最大 論理144px で truncate
              線分の中点に置き、線を隠す。ラベルが空なら箱ごと描かない

both:
  │ 田中 │◀─────┤幼馴染├─────▶│ 鈴木 │

none:
  │ 田中 │───────┤同郷├───────│ 鈴木 │

同じ 2 人の間に 3 本（法線方向に論理16px ずつオフセット）:
  ┌──────┐   ┌──役目├──   ┌──────┐
  │ 田中  │───┤ 兄 ├──────▶│ 鈴木  │
  └──────┘   └─憎んでいる├─  └──────┘

選択中のエッジ: 線と矢じりを accent・太さ 2 倍
```

- 端点は**ノード矩形の境界でクリップ**（中心同士を結び、矩形との交点で切る）
- 線は `muted` / 論理 1.5px（スクリーン 1〜2px にクランプ）
- 矢じりは論理 10px（スクリーン 5〜10px にクランプ）。**低倍率でも潰れない**
- **z 順はラベル箱が最前面**（ノードより上）。ラベルは関係の意味そのもので、隠れると図の意味が失われる
- **zoom < 0.6 ではラベル箱を描かない**

### 誤操作の戻し方（まとめ）

| いつ | どう戻すか |
| --- | --- |
| 相手を選ぶ前 | `キャンセル` / `Escape` / 背景タップ → **何も作られない** |
| 作ってしまった後 | 関係編集モーダルの **`この関係を削除`**（**Undo が無いので、これが直後に取り消す唯一の経路**） |
| 向きを間違えた | 関係編集モーダルの **`入れ替え`** |
| 無効な場所で離した（PC） | 何も作らずガイドが消える。**エラーメッセージを出さない** |

## G. 関係編集モーダル（375px）

```
┌───────────────────────────────────┐
│ 関係                          [✕] │ ← Modal（既存プリミティブ）
├───────────────────────────────────┤
│ ● 田中 太郎  →  ● 田中 桜         │ 読み取り専用（識別色ドット + 名前）
│                     [ 入れ替え ]  │ from / to を入れ替える
│                                    │
│ ラベル                             │
│ ┌───────────────────────────────┐│
│ │ 兄妹                           ││ InlineText（枠付き・デバウンス保存）
│ └───────────────────────────────┘│ 空でもよい
│                                    │
│ 向き                               │
│ ┌────────┬────────┬────────┐    │ SegmentedControl size="touch"
│ │● 田中→桜│ 田中↔桜 │ 線のみ  │    │ 記号だけにせず名前を入れる
│ └────────┴────────┴────────┘    │ 選択中は面の色 + font-semibold
│                                    │
│ [ この関係を削除 ]        [ 閉じる ]│ 削除は variant="danger"
└───────────────────────────────────┘
```

- **保存ボタンを置かない**。ラベルはデバウンス保存、向きは押した瞬間に反映
- 開く経路は 3 つ: ① 結線直後 ② エッジのラベル箱をタップ ③ 関係リストの行から

```
│ │ 兄妹                           ││ InlineText（枠付き / min-h-11）
│ └───────────────────────────────┘│
│ ┌───────┬───────┬───────┐[入替] │ 向き 3 択（44px）
```

- **行はその場で編集できる**（別モーダルを開かせない）。「編集は流れを止めない」原則

- 追加した行は末尾に付き、`ring-accent` を約 1.5 秒当てて示す
- 関係 0 件: `text-muted text-xs` の 1 行「まだ関係がありません。下の「＋ 関係を追加」か、
  図でノードを選んで「＋ 関係」から作れます。」

## I. グループの UI（375px）

### I-1. グループ割り当て（ノード選択 → `グループ`）

```
┌───────────────────────────────────┐
│ グループに入れる              [✕] │ ← Modal
├───────────────────────────────────┤
│ ○ 未所属                           │ 各行 44px 高
│ ● 王国側                  （5 人）│ 現在の所属に ● + font-semibold
│ ○ 帝国側                  （3 人）│ **記号 + 太字の二重表現**（色だけに頼らない）
│ ○ 〇〇家                  （0 人）│
├───────────────────────────────────┤
│ ＋ 新しいグループを作って入れる      │ 押すと下の入力欄が開く
│ ┌────────────────────┐ [ 作成 ]  │ （最初から開いていると既存を選ぶ導線が埋もれる）
│ │ グループ名             │          │
│ └────────────────────┘          │
└───────────────────────────────────┘
```

## L. PC 幅（`md` 以上）との差分

375px 基準で決めた内容のうち、PC 幅で**変わるもの**と**変わらないもの**。
（ui-spec の原則: 競合したらスマホを優先する）

| 画面要素 | 375px（基準） | `md` 以上 | 差分 |
| --- | --- | --- | --- |
| モード切替 | 幅いっぱいの 2 分割・44px 高 | 左寄せ・内容幅・32px 高 | **変わる**。`w-full md:w-auto` + `size="touch"` の CSS のみ。JS の分岐なし |
| 初期倍率 | 30 人で約 0.43 → **縮小表現**（文字なし） | 1200×700 なら約 0.69 → **通常表現**（文字が読める） | **変わる**。同じ zoom-to-fit の式で自然にそうなる（LOD 閾値 0.6） |
| ノードのドラッグ移動 | 通常表現（zoom ≥ 0.6）でのみ可 | 同じルール | **変わらない**。倍率の条件が同じなので、結果として PC は最初から動かせる |
| **結線** | **タップ 2 段階のみ**（F 章） | **タップ 2 段階 + ドラッグ結線ハンドル** | **変わる**。ハンドルは `md` 未満では出さない（常時表示すると図が点で埋まり、44px にするとノードより大きくなる）。**タップ 2 段階は PC でも使える**ので機能差は無い |
| エッジ線のクリック | **タップ対象にしない** | 24px 幅の透明ストロークでクリック可 | **変わる**。`md` 未満の代替は関係リスト（H 章） |
| エッジのラベル箱 | タップ可（44px 未満・補助経路） | クリック可 | **変わらない**（サイズも当たり判定も同じ） |
| ノードアクションバー | 下端固定・2 行に折り返す | 下端固定・**1 行に収まる** | **変わらない構造**。`flex-wrap` + `size="touch"` の自然な結果で、実装分岐は無い |
| 関係リスト / グループ管理 | `Drawer` = 実質フルスクリーン | `Drawer` = 右 448px | **変わらない**（`Drawer` の既存 responsive 挙動そのまま） |
| 関係編集 / グループ割り当て | `Modal` | `Modal` | **変わらない** |
| 浮遊コントロール（⊕ ⊖ ⟳） | 各 44×44 | 各 32×32 | **変わる**。`IconButton size="touch"` の既定挙動 |
| ノードの当たり判定 | 最小 44×44 スクリーン px | 同じ | **変わらない**（PC でも広い方が誤クリックしにくい） |
| ドラッグ開始しきい値 | 8px | 8px | **変わらない**（既存カンバンの 6px と近い値で揃える） |
| ノードの見た目・エッジ・グループ枠 | B〜D 章のとおり | 同じ | **変わらない** |
| StoryTabs | 相関図モードでは出さない | 同じ | **変わらない**（spec 5 / Q6） |
| Escape で移動を中止 | **無い**（キーボードが無い） | **ある** | **変わる**。スマホに中止手段が無いことは認めたうえで、ui-spec 8-2 の 5 つの仕掛けで発生確率を下げている |

- 「変わる」行が実装で分岐が要る箇所。ただし**すべて CSS の responsive utility か、
  `size="touch"` の既定挙動で吸収できる**（`matchMedia` による JS 分岐は 1 箇所も無い）
- 例外は「エッジ線のクリック」「ドラッグ結線ハンドル」の 2 つ。ここはポインタの有無に
  依存するため、`md` のブレークポイントで**描画するかどうか**を切り替える
  （`hidden md:block` 相当。既存の [06-ui-design.md](../../../docs/02-development-docs/06-ui-design.md) §8 と同じ流儀）

## M. 44px を満たさない要素の再掲（ワイヤーフレーム上の位置）

| 要素 | 図中の場所 | 代替手段 |
| --- | --- | --- |
| エッジのラベル箱（高さ 約 20px @zoom 1.0） | C 章 `┤兄妹├` | **H 章の関係リスト**（`関係 N` ボタン → 全件 / ノード選択 → そのキャラの関係のみ） |
| エッジの線（1〜2px） | C 章の線 | 同上。`md` 未満では線をタップ対象にしない |
| ドラッグ結線ハンドル（24px） | F 章の `◉` | `md` 未満では**表示しない**。結線は F 章のタップ 2 段階 |

**375px で関係を追加 / ラベル編集 / 向き変更 / 削除する経路（タップ 2 段階 + 関係リスト）は
すべて 44px を満たしている。** 上の 3 つは「あれば速い」補助経路であり、
無くても v1 の機能は 375px で完結する。
