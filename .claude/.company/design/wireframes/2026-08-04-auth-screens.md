```
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│ ← スクリム bg-black/30
```

```
                                    ┌──────────────────┐
                     [＋新しい作品][T]│ ← [T] クリックで開く
                                    └┬─────────────────┘
                                     │
                          ┌──────────▼──────────┐ w-72
```

## E. 保存状態インジケータ（`SaveStatusIndicator`）

### E-1. `/projects/[projectId]` ヘッダ内（Drawer が閉じている時）

```
┌──────────────── 375px ────────────────┐
│ ← 一覧   [ 作品タイトル input      ]  [キャラクター 3]│
│ ログライン・メモ…                                    │
│ 保存済み                                            │ ← text-muted text-[11px]
├────────────────────────────────────────────────────┤
│ [第一幕] [第二幕] [+ ストーリー]                       │
```

保存中:
```
│ ...(同上)...                                        │
│ 保存中…                                              │ ← text-muted
```

失敗（タップで再試行）:
```
│ ...(同上)...                                        │
│ [ 保存できませんでした ]                              │ ← text-danger, tap で retrySave()
│   title/aria-label に「通信を確認してください」を保持
```

### E-2. `SceneEditor` / `CharacterPanel` の Drawer タイトル内（Drawer が開いている時）

```
┌──────────────────────────────────┐
│ シーン編集 第一幕      保存済み  [ ✕ ]│ ← title に併記。タイトルは truncate、
│                                    │   インジケータは shrink-0 で常に見える
├──────────────────────────────────┤
│ ...フォーム...                      │
├──────────────────────────────────┤
│ [ 削除 ]         [ 複製 ] [ 閉じる ]│ ← footer (既存のまま)
└──────────────────────────────────┘
```

- Drawer が画面全体を覆う（`fixed inset-0 z-50`）ため、ページヘッダのインジケータ（E-1）は
  この間は見えない。**同じコンポーネントを Drawer 側にも差し込むことで、常にどちらか一方が
  見えている状態を作る**（詳細は ui-spec 6-1 章）
- PC 幅でも同じ構造・同じ文言。差分は無い
