## 参照ビジュアル（社長提示のスクリーンショット・**原文のまま転記**）

> **画像は Claude 親オーケストレータのみが見た。企画・デザイン・開発はこの記述しか手がかりが
> 無い。ここを一次情報として扱い、書き換えない。**

GitHub 上でレンダリングされたダーク配色のアーキテクチャ図。以下の特徴を持つ:
- 角丸の矩形ノード。ノード内は 1〜3 行のテキスト (太字の名前 + 補足行)。
  例:「frontend/ サイト / Next.js 静的」「tool/ 描画エディタ / React + WebGL 2 + WASM」
- ノードを囲む**グループ枠**。枠の左上にグループ名ラベル。
  例:「ブラウザ」「Vercel — pairbrush.com」「Fly.io」。枠は入れ子ではなく単層。
- ノード間を結ぶ**ラベル付きの有向矢印**。ラベルは線の中央に小さな箱で乗る。
  例:「REST」「WebSocket (直結)」「MCP + OAuth 2.1/PKCE」「HTTP」。
  グループ枠をまたぐ線もある (ブラウザ内のノード → Fly.io 内のノード)。
- 図の右上と右下に**操作コントロール**が浮いている:
  右上に「全画面 (↔)」「コピー」、右下に上下左右の**パン十字ボタン** +
  中央に**リセット (⟳)** + 拡大 (⊕) / 縮小 (⊖) の**ズームボタン**。
- 図全体は本文カラムの中に収まり、キャンバスは横長。背景は無地のダーク。

社長が言う「これを GUI で繋げる」は、**この種の図を mermaid 等のテキストで書くのではなく、
画面上でノードを配置し、ノード同士をドラッグで結線して作れるようにする**という意味。

## 新たに判明したリスク（開発部報告・2026-08-04）

`accounts-and-server` の**切替コミット**（`persist` / `idbStorage` の読み書きを外すコミット）が
相関図の本実装より**先に**入ると、相関図の移行方針の**決定 2（`merge` で相関の 2 配列の存在を
保証する）が不要になり、代わりに決定 6 の Prisma 受け皿 ＋ Server Action 側の実装が必要になる**
（本実装が前提とする拘束条件が入れ替わる）。

- 秘書決裁 R-1 は「(a) ローカル版に先に載せる」なので、順序としては相関図の本実装が先という
  前提だったが、**2 つの本実装が同じ週に走る**ため、**切替コミットの直前に相関図の進捗を
  必ず確認する**こと。
- 出典: [移行方針チケット 7-1](../../dev/tasks/2026-08-04-character-relationship-graph-data-migration.md#7-1-作業ツリーの変化による影響2026-08-04-2045-時点)。
