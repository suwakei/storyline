## 社長への確認事項（回答が無くても既定で前進する）

**質問**: 「json で書き出すのはやめて」は次のどれですか。

- (a) バックアップ手段としての JSON 書き出し機能そのものを廃止する
- (b) DB が正本になるので JSON をバックアップの主手段にするのはやめる（移行用途では残す）
- (c) 移行も JSON 経由をやめる（IndexedDB からサーバへ直接引き取る）

**回答が無い場合の既定**: **(b) で進めます。**
理由は、いま作品の正本は IndexedDB だけで `*.storyline.json` が唯一の避難路であり、
サーバ移行が完了する前に書き出しを消すと**既存の作品を DB へ持ち込む手段が無くなる**ため
（復旧不能）。移行完了後に書き出し機能を削除するのは可逆な判断として後から実施できます。

**判断期限の目安**: planning spec の着手前（本日中）。以降は (b) 前提で spec を確定させ、
後から覆った場合は決裁記録に追記して差分を追える形にします。
