## 概要

スマホからの利用と複数人での利用のため、ブラウザ完結をやめてアカウント制に移行する。
方式は社長決裁で確定済み（Google ログイン / 作品は本人のみ / Neon+Prisma / Blob）なので、
このチケットは **移行に伴って決まっていない仕様の穴を塞ぐ** ことが目的。後続の dev 実装が
判断に迷わない状態を作る。

**2026-08-04 の追加指示で前提が 2 点変わった**（詳細は決裁記録の「追記」節）。
スマホは「対応する画面のひとつ」ではなく**メイン想定**になり、JSON 書き出しの位置づけが
一時再保留になった（その後 (b) で社長確定）。この 2 点が下記「決めること」の 7〜9 に相当する。

## 決めること

1. ログイン前に見せる画面（ランディングを作るか、いきなり Google ボタンだけか）
2. 未ログイン時のルーティング（`/` を保護するか、`/login` へ飛ばすか）
3. 既存ローカルデータを持つユーザの導線（初回ログイン後に「JSON を読み込む」を促すか）
   — **移行手段は JSON 経由で確定（決定 7 = (b)・社長確定済み）**。決めるのは促し方と画面
4. ローカル版の扱い（決裁では「廃止」。移行猶予期間を設けるか、いつ IndexedDB 読み出しを消すか）
5. 作品数・シーン数・画像サイズの上限（Neon / Blob の無料枠を守れる値）
   — スマホのカメラロール画像が入る前提で見積もること
6. 退会・データ削除の要否（個人利用なので最小で良いか）
7. **【追加】JSON 書き出し／読み込みの存廃** → **(b) で社長確定済み（回答日 2026-08-04）**
   - 確定内容: 「DB が正本になるのでバックアップの主手段としては廃止するが、
     既存 IndexedDB データをサーバへ持ち込む**移行経路としては残す**」
   - 制約: 移行完了前に書き出しを消さないこと（既存作品を DB へ持ち込む手段が失われるため）
8. **【追加】モバイルファーストの適用範囲と判断基準**
   - PC とスマホで仕様が競合したときは**スマホを優先する**（決裁で確定）
9. **【追加】オフライン利用を「保留のまま」にする理由を 1 行残す**

詳細は [本稿 0-2](../specs/2026-08-04-accounts-and-server-spec.md) を参照。

| # | 何を直したか | 重大度 |
| --- | --- | --- |
| A | 「社長未回答のため既定 (b)」の記述 3 箇所を「2026-08-04 社長が明示回答」へ。覆る可能性の注記も削除 | 中（誤読の元） |
| B | **「移行は PC 前提。スマホには移行すべきデータが存在しない」は事実として誤り**。IndexedDB は端末・ブラウザごとに独立するため、スマホでローカル版を開いていればそこにしか無い作品がある。「旧データがある端末ごとに書き出す」へ修正し、端末の洗い出しを切替の前提条件（Q4）にした | **高（データ消失に直結）** |
| C | 安全弁 1「実質の猶予は無期限」は言い過ぎ。成立条件（同一プロファイル / 同一オリジン / サイトデータ未削除 / dev 環境保有者のみ）を明記。**安全弁 2 をリリースゲートへ格上げ**、**安全弁 4「切替後は旧版で編集しない」を追加** | **高（データ消失に直結）** |
| D | 上限表に**ユーザ数の上限が無かった**。見積り全体が「5 人」前提なのに前提が上限化されていない。**ユーザ数 6 人（DB が律速）を明記**し、許可リストの人数と結び付けた | 高（無料枠の防衛） |
| E | インポート JSON 1 ファイル上限 20 MB → **50 MB**。旧 JSON は data URL サムネイルを含み base64 で約 1.33 倍になるため、サムネイル付き 150 シーンで 20 MB を超え、**移行そのものが弾かれる**恐れがあった | 高（移行が通らない） |
| F | 縮小後 300 KB 超の画像を**拒否 → まず再圧縮**へ。カメラロールの写真は 640〜800px でも 300 KB を超えうる。拒否は判断軸「書く手を止めない」に反する | 中 |
| G | **サーバ化後の保存の粒度・保存失敗時の扱いが未定義**だった上、13 章で「セッション切れ時の入力復元」を「やらないこと」に入れており「保存失敗で入力が消えてよい」と読めた。原則 1-2 を新設し「**保存に失敗しても画面の入力を消さない**」を MVP に入れた | **高（書いた文章が消える）** |
| H | サムネイルの**公開範囲が未定義**。Blob の公開 URL は「作品は本人だけ」と厳密には衝突する。v1 の判断を明記し、社長の受容確認を Q8 として追加 | 中 |

補足追加（差し替えではないもの）: セッション有効期間 30 日 / 移行の受け入れ条件（往復で件数と
並び順が一致すること）/ 一望性のためページングしない / アカウント削除は Blob → DB の順 /
許可リストは**決裁に無い企画部の追加提案**である旨の明示 / 未確認事項の一覧（本稿 14-2）。
