## 概要

デザイン部が固めた縦リスト仕様を実装する。サーバ移行と独立して出せるので、
これだけ先に入れればローカル版のままスマホで読める状態になる。

**2026-08-04 の前提変更**: 社長の利用想定が「スマホがメイン」に更新された。本チケットは
「付加的なスマホ対応」ではなく**メイン利用形態を成立させる作業**であり、サーバ移行と同格の
最優先ラインに置く（優先度 中 → 高）。サーバ移行はブロッカー 3 件で止まりうるのに対し、
こちらは前提が design の UI 仕様のみなので、**最も早くユーザ価値が出る経路**でもある。

## 作業

- 狭い画面で [Board](../../../../src/components/board/Board.tsx) を縦リスト表示に切り替える
- 並べ替え操作を仕様どおりに（ドラッグ維持なら dnd-kit の
  [TouchSensor](../../../docs/03-library-docs/03-dnd-kit-doc.md) 設定、ボタン方式ならストア操作の追加）
- [Drawer](../../../../src/components/ui.tsx) とヘッダを縦画面に収める
- ストアに操作を足す場合は `src/lib/` 側を先に確定させてから UI を書く

## 完了条件
