全部署の進行中タスク一覧を表示してください。

## 走査対象

**各部署の `tasks/` のみ**を走査する (`.claude/.company/{部署}/tasks/`)。
`tasks/` がステータスの唯一の一次情報。`specs/` `ui-specs/` `content/` 等は成果物
(ドキュメントライフサイクル語彙 ドラフト/本稿/確定 を持つ) で**走査対象外**、`inbox/` は
未トリアージ連絡で対象外。詳細は [.company/CLAUDE.md](../../.company/CLAUDE.md) の
「ディレクトリ構成と一次情報」を参照。

| 部署 | 走査ディレクトリ |
| --- | --- |
| 開発部 | `dev/tasks/` |
| 企画部 | `planning/tasks/` |
| デザイン部 | `design/tasks/` |
| 広報部 | `pr/tasks/` |

## ステータス検出 (チケット先頭メタブロックから)

- パターン: `- ステータス: \*?\*?(未着手|進行中|レビュー中|完了)\*?\*?`
- **完了は除外**。それ以外をすべて収集
- パターンが無いファイル (README 等) はスキップ

## 優先度検出

- パターン: `- 優先度: \*?\*?(高|中|低)\*?\*?`
- 行が無ければ「中」とみなす

## 並び順 (多段ソート)

1. **部署順**: 開発部 → 企画部 → デザイン部 → 広報部 (組織図順)
2. **優先度**: 高 → 中 → 低
3. **ステータス**: 進行中 → レビュー中 → 未着手
4. **起票日昇順** (古いものを上に = 滞留が見える)

## 出力フォーマット

```
## 📊 タスクステータス (生成: YYYY-MM-DD)

合計: N 件 (進行中 X / レビュー中 Y / 未着手 Z)

### 開発部 (N 件)
- [{ステータス}] {タスク名} (優先度: {高/中/低}, 起票: YYYY-MM-DD) ([相対パス])

### 企画部 (N 件)
- ...
（以下、デザイン / 広報 の順）
```

タスクが 0 件の部署は「### 部署名 (0 件) — _アクティブタスクなし_」と出す (セクション自体は省略しない)。
